# Design Brief: Coolaboratory.com

## Problem Statement
The current site (live since 2011) is stale and no longer functions as a credible presence. Andrew needs a simple, single-page site that establishes legitimacy for his 1099 contracting entity (UX, physical AI, frontier AI model training, maker community support) without soliciting contract work, and hands off interested visitors to milmoe.com.

## Users
Recruiters, hiring managers, and conference contacts who encounter andrew@coolaboratory.com or the coolaboratory.com domain and want to confirm it's a real, legitimate entity. Standard accessibility baseline: mobile visitors at conferences, screen reader users, low vision.

## Design Direction
One static page. No forms, no subpages, no external links besides milmoe.com. Maker-punk/DIY register per the 2009 manifesto (Cool + Collaboration + Laboratory + Labor) — deliberately distinct from milmoe.com's clinical enterprise system. Original 2009 logo used as-is.

Page structure (single column, top to bottom):
1. Logo / wordmark (original 2009 asset, unmodified)
2. What Coolaboratory is + services (UX, physical AI, frontier AI model training, maker community support)
3. Historical blurb: origins in the Oakland/Bay Area — information architecture and UX for global brands via local digital agencies, plus a resource for Bay Area Makers; later transitioned to UX and physical AI for hardware startups in Chicago
4. Low-key note that Coolaboratory is not currently taking on part-time/contract work
5. Contact (andrew@coolaboratory.com)
6. Link to milmoe.com

No photo sidebar, no Flickr archive link (considered and cut).

## Constraints
- Single page, no forms, no subpages
- Don't imply openness to contract work — say plainly that it's not being sought right now
- No mention of or link to milmoeartcollection
- Hosted on GitHub Pages; DNS will be repointed from current host as a test case
- Nothing carried forward from the 2011 site (content or structure)
- Logo used unmodified — original file, no redraw

## Existing Design System
None reused. milmoe.com's system (Space Grotesk / Inter / IBM Plex Mono, clinical/precise) exists but is explicitly NOT applied here — Coolaboratory gets its own distinct feel.

## Taste Direction (Early Signal)
Maker-punk, DIY, "if you spend the time doing it, do it right." 2009 manifesto as voice reference (Cool / Collaboration / Laboratory / Labor / Fine / Experience). Logo's existing palette (deep purple, warm rust/brown) is the natural anchor since the logo stays as-is.

## Success Criteria
Andrew is comfortable using the domain/email professionally at conferences and elsewhere; visitors immediately read it as a legitimate, distinct entity with real history; visitors interested in hiring Andrew are routed to milmoe.com.

## Out of Scope
Contact forms, subpages, blog, case studies, contract-work solicitation, milmoeartcollection, photo sidebar / Flickr archive link.
